# Lantern Library

Canonical repository for Project Lantern's inherited/seeded knowledge packages.

This repository is **knowledge/data**, not Lantern runtime authority. Seed packages are versioned inherited structures that Lantern may load through the reviewed Foundation Library interface. They do not grant permissions, self-install code, or convert empirical claims into unquestionable truth.

## Foundation Core 45

The first milestone is a minimum inherited curriculum of 45 packages. Package boundaries are conceptual/update boundaries; each package may contain many definitions, rules, counterexamples, examples, and validation cases.

See `foundation/CORE_45_CHECKLIST.md` once added.

## Inheritance classes

- `FORMAL_CORE`: protected formal structures; changed only by reviewed library/software updates.
- `CONCEPTUAL_CORE`: stable distinctions used for reasoning.
- `METHOD`: structured ways of investigating questions; revisable.
- `EMPIRICAL_INHERITED`: evidence-revisable human empirical knowledge.
- `MODEL_INHERITED`: theories/models with scope, evidence, alternatives, and history.
- `HISTORICAL`: claims about historical events or belief states.
- `NORMATIVE_LENS`: frameworks for reasoning, never silently promoted to objective truth.

## Design rule

Seed what humanity already knows well enough that rediscovery would waste compute. Preserve provenance, scope, epistemic type, and revisability so Lantern can later challenge or refine inherited empirical knowledge through evidence.
