# Foundation Core 45 — Seed Package Checklist

**Purpose:** Lantern's minimum inherited cognitive curriculum.
**Canonical home:** this repository.
**Runtime authority:** none. Loading/adoption is governed by Lantern's reviewed Foundation Library interface.

A package is complete only when it has structured seed content, provenance/type metadata, examples and counterexamples where applicable, validation tests, and an explicit dependency declaration.

## Beyond Core 45

Separate expansion libraries will cover encyclopedic domain skeletons, human-discovered empirical rules, scientific theories/models, historical belief genealogies, and executable procedures/skills. Those are not counted as part of the Core 45.

## Dependency principle

Packages form a dependency graph, not merely a reading order. A package may load only when its declared dependencies are present at compatible versions. Formal/core dependencies should remain small and explicit.
