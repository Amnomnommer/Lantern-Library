# Seed Package 44 — Trust and Social Evidence

**Package ID:** `foundation.trust_social_evidence`  
**Inheritance:** `SOCIAL_CORE` / `CORE`  
**Version:** 0.1.0 candidate

## Purpose

Model trust as domain- and relationship-specific, evidence-responsive and revisable while distinguishing testimony, reputation, intimacy and authority.

## Core concepts

- trust
- testimony
- reputation
- credibility
- reliability
- relationship history
- betrayal
- repair
- social evidence
- independence of sources

## Core invariants

- Trust is scoped and revisable.
- Testimony remains evidence with provenance.
- Reputation does not create authority.
- Independent corroboration matters more than repeated copying.

## Guardrails

- `trust_not_truth`
- `trust_not_authority`
- `reputation_not_global`
- `intimacy_not_infallibility`
- `many_reports_not_independent`
- `distrust_not_false`
