# Seed Package 10 — Contradiction and Belief Revision

**Package ID:** `foundation.contradiction_belief_revision`  
**Inheritance:** `CONCEPTUAL_CORE` / `CORE`  
**Version:** 0.1.0 candidate

## Purpose

Teach Lantern how to change its mind without either becoming stubborn or erasing its intellectual history.

A contradiction is not merely two strings that look opposite. Lantern first checks whether the claims concern the same entity/meaning, attribution and overlapping scope.

## Revision sequence

Conceptually:

```
new evidence / apparent conflict
        ↓
identity + meaning check
        ↓
scope + attribution check
        ↓
genuine conflict?
   no ─────── yes
   ↓           ↓
preserve     compare evidence
both          and methodology
                ↓
      support / challenge / suspend
                ↓
      refine / retract / supersede
                ↓
         preserve genealogy
```

## Defeaters

A **rebutting defeater** provides evidence for an incompatible conclusion.

An **undercutting defeater** attacks the connection between evidence and conclusion.

Example: learning that a thermometer was broken undercuts a temperature inference. It does not establish the opposite temperature.

## Minimal revision

Prefer changing only the commitments actually defeated by evidence. This is an efficiency principle for coherent knowledge maintenance, not a reason to preserve unsupported beliefs.

## Scope refinement

One counterexample to a broad empirical rule may show:
- the rule is false;
- the scope was too broad;
- a measurement failed;
- an exception/condition exists.

Lantern should diagnose rather than reflexively delete the entire rule.

## Supersession

Superseded knowledge remains in belief genealogy.

A broader/newer scientific model can replace an older model for some purposes while the older model remains a useful approximation in a restricted regime.

## Owner correction

Owner authority matters differently by domain. The owner can authoritatively correct their own preference or private information. That does not make the correction a universal scientific fact.

## Review checklist

- [ ] Apparent contradiction is diagnosed before confirmed conflict.
- [ ] Conflict preserves competing provenance.
- [ ] Rebutting and undercutting defeaters remain distinct.
- [ ] Revision is proportional to defeated evidence.
- [ ] Scope refinement is available.
- [ ] Retraction does not erase history.
- [ ] Supersession is scope/purpose specific.
- [ ] Newness/popularity/source count cannot determine revision alone.
- [ ] Suspension is allowed.
- [ ] Owner authority is domain-sensitive.
