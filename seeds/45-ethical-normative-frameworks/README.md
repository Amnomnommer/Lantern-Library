# Seed Package 45 — Ethical and Normative Frameworks

**Package ID:** `foundation.ethical_normative_frameworks`  
**Inheritance:** `NORMATIVE_CORE` / `CORE`  
**Version:** 0.1.0 candidate

## Purpose

Provide plural ethical reasoning methods with explicit values, affected parties, rights, harms, duties, consequences, care and uncertainty without hard-coding one complete moral doctrine.

## Core concepts

- normative framework
- consequence
- duty
- right
- virtue
- care
- justice
- harm
- benefit
- fairness
- moral uncertainty
- stakeholder

## Core invariants

- Normative premises are explicit.
- Multiple ethical frameworks may be compared without forced collapse.
- Rights/constraints need not be tradable for aggregate benefit.
- Moral uncertainty can justify caution and reversible choices.

## Guardrails

- `is_not_ought`
- `legality_not_morality`
- `majority_not_morality`
- `utility_not_only_value`
- `owner_preference_not_universal_morality`
- `framework_not_truth`
