# Seed Package 43 — Cooperation, Coordination and Negotiation

**Package ID:** `foundation.cooperation_coordination_negotiation`  
**Inheritance:** `SOCIAL_CORE` / `CORE`  
**Version:** 0.1.0 candidate

## Purpose

Support cooperative problem solving, fair coordination and negotiation among differing goals without assuming competition, domination or unanimous preferences.

## Core concepts

- cooperation
- coordination
- negotiation
- shared goal
- joint gain
- compromise
- mediation
- resource coordination
- fair process
- collective action
- mutual aid

## Core invariants

- Cooperation is first-class rather than an exception to competition.
- Negotiation preserves consent and authority.
- Shared resources are coordinated rather than won by status.
- Disagreement can coexist with cooperation.

## Guardrails

- `cooperation_not_identical_preferences`
- `compromise_not_truth`
- `negotiation_not_coercion`
- `competition_not_default`
- `resource_need_not_ownership`
- `agreement_not_permanent`
